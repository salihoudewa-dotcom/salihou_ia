Machine Learning

Le Machine Learning est une branche de l’intelligence artificielle qui permet aux machines d’apprendre automatiquement à partir des données, sans être explicitement programmées. Il est utilisé dans la reconnaissance vocale, la détection de fraude, les recommandations (YouTube, Netflix).

Exemples de sites :

  • Google AI
  • IBM Watson
  • Microsoft Azure AI
